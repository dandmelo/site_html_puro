O que é HTML?

HTML significa HyperText Markup Language (Linguagem de Marcação de Hipertexto). É utilizada para estruturar o conteúdo de páginas da internet.

Com HTML, definimos títulos, parágrafos, imagens, links, listas, tabelas e outros elementos. Ele não é uma linguagem de programação, mas uma linguagem de marcação.

Estrutura Básica de um Documento HTML

Todo documento HTML segue uma estrutura básica:

<!DOCTYPE html>
    <html lang="pt-BR">
    <head>
        <meta charset="UTF-8">
        <title>Minha página</title>
    </head>
    <body>
        <h1>Olá, mundo!</h1>
        <p>Minha primeira página HTML.</p>
    </body>
    </html>
  • <!DOCTYPE html>: informa ao navegador que o documento utiliza HTML5.
  • <html>: elemento raiz da página.
  • <head>: contém informações sobre o documento.
  • <title>: define o título exibido na aba do navegador.
  • <body>: contém o conteúdo visível da página.

Principais Tags HTML

As tags são elementos utilizados para identificar e organizar os diferentes tipos de conteúdo.

1. Títulos e textos

  • <h1> até <h6>: títulos e subtítulos.
  • <p>: parágrafo.
  • <strong>: dá importância ao texto (geralmente em negrito).
  • <em>: dá ênfase ao texto (geralmente em itálico).
  • <br>: quebra de linha.
  • <hr>: separação temática, geralmente exibida como uma linha.

2. Links e imagens

  • <a>: cria links para outras páginas ou seções.
  • <img>: exibe imagens.

4. Organização semântica

  • <header>: cabeçalho.
  • <nav>: área de navegação.
  • <main>: conteúdo principal.
  • <section>: seção temática.
  • <article>: conteúdo independente.
  • <footer>: rodapé.

Exemplos Práticos

Exemplo de título e parágrafo

<h1>Meu primeiro site</h1>
    <p>Estou aprendendo HTML!</p>

Exemplo de imagem

<img src="imagem.jpg" alt="Descrição da imagem">

O atributo src indica o caminho da imagem e alt fornece uma descrição textual.

Exemplo de link

<a href="https://www.google.com" target="_blank" rel="noopener noreferrer">Acessar o Google</a>
  • target="_blank" → Abre em nova guia.
  • rel="noopener" → Impede acesso à página original.
  • rel="noreferrer → Não informa a origem da navegação.

Exemplo de lista

<ul>
        <li>Primeiro item</li>
        <li>Segundo item</li>
    </ul>
