# Aprenda HTML
Um guia básico para entender a estrutura das páginas web.
Site didático sobre a linguagem HTML, com uma estrutura simples, organizada e utilizando os próprios elementos nativos do HTML.
1. Estrutura do site
- Cabeçalho com título e subtítulo.
- Menu de navegação por links internos.
- Introdução à linguagem HTML.
- Explicação das principais tags.
- Listas ordenadas e não ordenadas.
- Tabela de referência das tags.
- Exemplos de códigos HTML.
- Links externos para documentação.
- Rodapé.
- Favicon (ícone exibido na aba do navegador)
